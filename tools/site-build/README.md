# Website page builder

The public website pages at the repo root (index.html, pricing.html, faq.html,
signin.html, about.html, schools.html, contact.html, privacy.html, terms.html,
refunds.html, 404.html) are generated by these scripts so the header, footer and
page head stay identical everywhere.

**Edit the page text here, not in the root .html files**, then run:

    python3 tools/site-build/build.py

and commit both the scripts and the regenerated pages.

- `common.py` holds the shared head, header, footer, links and prices.
- `p_home.py` is the home page; `p_main.py` is Pricing, FAQ and Sign in;
  `p_docs.py` is About, Schools, Contact, Privacy, Terms, Refunds and 404.
- Styles live in `/site.css`. Bump `CSS_V` in `common.py` whenever it changes.
- The app itself lives in `/app/index.html` and is NOT built by this.

Plain Python 3, no packages to install. GitHub Pages serves the output as-is.
